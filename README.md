# Titanic Survival Prediction

## Project Overview
This project predicts Titanic passenger survival using Python and Machine Learning.

## Project Objectives
- Explore and analyze the Titanic dataset.
- Perform data cleaning and feature engineering.
- Visualize important patterns in passenger survival.
- Train and evaluate Machine Learning models.
- Generate predictions for the Kaggle competition.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Notebooks

### 1. Titanic_EDA.ipynb
Exploratory Data Analysis, data visualization, missing value analysis, and feature exploration.

### 2. Titanic_ML.ipynb
Feature engineering, model training, model evaluation, and Kaggle predictions.

## Machine Learning Models
1. Logistic Regression
2. Decision Tree
3. Random Forest
